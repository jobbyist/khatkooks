# Khat Kooks

Build a premium, mobile-first catering and local cuisine showcase website for Khat Kooks (logos attached), a South African culinary brand founded by Lisa Khatshiwe.

The objective is to establish a luxurious digital presence that showcases authentic African cuisine through beautiful food photography while making it effortless for individuals, families, event planners, and businesses to request catering quotations.

This is not an e-commerce website. The primary conversion goal is generating qualified catering enquiries and quote requests.
